## 📖 О проекте

CipherVault — это безопасный оффлайн-менеджер паролей для Windows, который помогает надёжно хранить и управлять вашими учётными данными. Приложение построено на .NET 8 и WPF, использует стандарты шифрования (Argon2id + AES-GCM) для защиты данных.

### ✨ Возможности

- 🔒 **Шифрование военного уровня** — ключевая деривация Argon2id + шифрование AES-GCM
- 🛡️ **Безопасная работа с памятью** — пароли хранятся в защищённых буферах памяти
- 🎲 **Генератор паролей** — создание сложных настраиваемых паролей
- 🌍 **Мультиязычность** — поддержка английского и русского языков
- 📝 **Журнал аудита** — отслеживание всех событий безопасности
- ⏱️ **Автоблокировка** — автоматическая блокировка хранилища при бездействии
- 📋 **Управление буфером обмена** — безопасный буфер с автоочисткой
- 🎨 **Современный интерфейс** — чистый интуитивный WPF-интерфейс с тёмной темой

## 🚀 Быстрый старт

### Требования

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или новее
- Windows 10/11 (x64)
- Visual Studio 2022 (рекомендуется) или VS Code

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/CipherVault.git
   cd CipherVault
   ```

2. **Соберите проект**
   ```bash
   dotnet restore
   dotnet build --configuration Release
   ```

3. **Запустите приложение**
   ```bash
   dotnet run --project CipherVault.csproj
   ```

### Публикация (единый исполняемый файл)

Создайте автономный исполняемый файл:

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Исполняемый файл будет расположен в папке `bin/Release/net8.0-windows10.0.26100.0/win-x64/publish/`

## 🏗️ Архитектура

CipherVault следует паттерну **MVVM (Model-View-ViewModel)** для чёткого разделения ответственности.

```
CipherVault/
├── Models/             # Модели данных (Credential и др.)
├── ViewModels/         # ViewModel (MainViewModel и др.)
├── Views/              # XAML представления (MainWindow.xaml и др.)
├── Services/           # Сервисы бизнес-логики
│   ├── StorageService.cs      # Хранение и шифрование хранилища
│   ├── PasswordGenerator.cs   # Генерация безопасных паролей
│   ├── AuditService.cs        # Логирвоание событий безопасности
│   ├── LocalizationService.cs # Поддержка нескольких языков
│   ├── SecureMemoryService.cs # Управление защищённой памятью
│   └── VaultManagerService.cs # Управление жизненным циклом хранилища
├── SecureControls/     # Пользовательские элементы безопасного ввода
├── Converters/         # XAML конвертеры значений
└── Resources/          # Ресурсы приложения и иконки
```

## 🔒 Функции безопасности

### Шифрование
- **Ключевая деривация**: Argon2id с настраиваемыми параметрами
  - Память: 128 МБ
  - Итерации: 3
  - Параллелизм: 4 потока
- **Шифрование**: AES-256-GCM со случайным nonce
- **Размер ключа**: 256 бит

### Защита памяти
- Учётные данные хранятся в обёртках `SecureBuffer`
- Конфиденциальные данные очищаются из памяти при освобождении
- Минимизировано время нахождения данных в открытом виде

### Защита хранилища
- Защита от перебора с экспоненциальной задержкой
- Блокировка аккаунта после 5 неудачных попыток
- Автоматическая блокировка хранилища при бездействии

### Журнал аудита
Все события безопасности записываются в журнал:
- Создание/открытие/закрытие хранилища
- Попытки входа (успешные/неуспешные)
- Изменения учётных данных
- Генерация паролей
- Предупреждения безопасности
